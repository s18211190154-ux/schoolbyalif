Accessibility statement

Our goal is for all families to access school information with clarity and confidence.

Template statement: review the published site with users and accessibility tools, then update this page with an accurate description of your school's commitment and contact process.

Design goals

This site template includes responsive layouts, keyboard-visible focus styles, labels for form controls, semantic headings, text alternatives for images and support for reduced-motion preferences.

Ongoing improvements

Accessibility is an ongoing process. Test page contrast, keyboard navigation, mobile zoom, screen-reader use and content clarity. Automated checks are helpful but do not replace testing with people.
