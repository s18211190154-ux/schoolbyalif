# School by Alif

A polished, responsive multi-page school website using HTML, CSS and vanilla JavaScript.

## Pages
- Home
- About the school
- Academics
- Admissions
- Campus life
- News and events
- Contact
- Privacy
- Accessibility

## Design and features
- Glassmorphic cards and navigation with a soft light theme
- Comfortaa headings and Manrope body text
- Responsive navigation for desktop, tablet and mobile
- Editable example imagery and school details in `assets/js/site-config.js`
- News category filters, accessible FAQ accordions and demo contact/admissions forms
- No build tools or frameworks required; suitable for GitHub Pages or Netlify

## Customize before launch
1. Edit `assets/js/site-config.js` to change the school name, tagline, email, phone, address, social links and image URLs.
2. Update sample school details, staff, dates, fees, policies and events in the HTML pages.
3. Connect the contact and admissions forms to a trusted form service or your own backend. Forms currently show an on-page demo confirmation only and do not send/store submissions.
4. Test all pages on a phone and desktop before sharing publicly.

## Publish with GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Once Pages finishes deploying, use the URL shown in that settings panel.

All copy, statistics, names and dates are demonstration content and should be verified/replaced before the site represents a real school.
