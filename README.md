# School by Alif

A responsive multi-page school website built with HTML, CSS and JavaScript. Features a glassmorphic visual style, Comfortaa typography, sample image URLs, responsive navigation, admissions information, academics, campus life, news, contact, and policy pages.

See the site files in the repository. Replace the demo school information and image URLs before public use. Contact and admissions forms are front-end demos and do not submit to a server yet.
