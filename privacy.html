Privacy notice

This starter page explains the current demo site's data behaviour. It is not a substitute for a legally reviewed school privacy policy.

Template notice: review this content against your actual practices and applicable law before publishing the website for a real school.

Forms and comments

Contact, admissions, complaint and guardian-comment interfaces on this version are previews. The forms do not send data to a server or retain it after the page is refreshed.

Public website data

The data folders in this repository are public and files can be read by anyone. They currently contain fictional examples. Do not place private student or guardian information, medical details, grades, attendance or complaints in these files.

External services

Example photographs and web fonts may load from third-party providers. Replace the sample imagery with approved assets and review any external service before launch.

Future authenticated portal

If student, teacher or guardian records are to be private, implement sign-in and server-side access controls. Hiding a link or putting private information inside browser JavaScript does not secure it.
